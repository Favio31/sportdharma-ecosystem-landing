## ️ Los 9 Pilares / The 9 Pillars

1. **Software Soberano** (Sovereign Software): Tus datos, tus reglas. Sin cajas negras.
2. **Transparente** (Transparent): Código abierto, procesos visibles, uso de IA declarado.
3. **Modular** (Modular): Piezas que se adaptan, no monolitos que atrapan.
4. **Educación Permanente** (Lifelong Learning): Conocimiento libre para fortalecer tu autonomía.
5. **Solidaria** (Solidarity): Apoyo real a atletas independientes, ONGs y comunidades remotas.
6. **Ecológica** (Ecological): Tecnología y prácticas con el menor impacto posible.
7. **Inclusiva** (Inclusive): Diseñado para todos, sin barreras de entrada (WCAG 2.1 AAA).
8. **Sostenibilidad Alineada** (Aligned Sustainability): Crecimiento real, no métricas de vanidad.
9. **Resiliente / Offline-First** (Resilient): El sistema produce y consume snapshots locales, operando sin red.

## ⚙️ El Motor: MASF + Curaduría Humana

Este ecosistema es impulsado por el **MASF** (Multi-Agent Swarm Framework), un pipeline de extracción web 100% local. 

**Nuestro flujo de trabajo (Human-in-the-Loop):**
1. 🔍 **MASF Scout**: Rastrea la web de forma ética, respetando `robots.txt`.
2.  **MASF Extractor**: Descarga, limpia y estructura la información con *grounding* (citas textuales verificables).
3. 👤 **Curaduría Humana**: El fundador valida, filtra y aprueba el contenido. Nada se publica sin este sello.
4. 🌐 **Publicación**: Solo lo aprobado se publica en la web y se comparte con la comunidad.
